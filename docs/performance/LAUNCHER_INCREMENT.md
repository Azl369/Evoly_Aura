# 自定义入口与负载面板：短时进程增量

日期：2026-11-22。范围：本次增量实现的诊断测量，不是完整性能预算验收。

## 方法与环境

同机先运行旧八卡片版本 `3a34b7f`，再运行包含本报告的功能版本。
均为 MSVC Release x64、C++20、Win32/Direct2D、无调试器，使用各自空白测试数据目录、
普通悬浮八卡片，原来的两秒系统采样保持开启。启动预热 8 秒，每阶段再采 8 个一秒样本，
下表为均值；阶段依次执行，包含 Windows 运行时预热，不能视为完全隔离的单组件成本。

Windows 11 25H2，build 26200.7840；Ryzen 7 7800X3D，16 逻辑线程，物理内存约 31.1 GiB；
单屏 2560×1440、125% DPI。系统枚举到 RTX 5070（32.0.15.9571）、
AMD 集显（31.0.14046.0）与虚拟显示设备；不能推广到其他机器或 DPI。
保留当前桌面环境，未固定后台应用、壁纸动画和电源状态；因此它不是静态壁纸 B0。

使用 `AuraMetrics.exe`，私有工作集来自工作集页面统计，私有提交来自 PrivateUsage；
CPU 按全部 16 个逻辑处理器归一化。同时记录 handles、GDI/USER 和 GPU/DWM 计数器。
`Test-CustomLaunchers.ps1` 创建合成 `.lnk`，仅启动写入测试标记后退出的受控小程序，
不启动用户应用；被启动目标不在稳态采样期间运行。应用自身保持单进程，无额外常驻编辑器。
原始 CSV、测试入口路径与本机日志只保留在 D 盘私有临时目录，不提交仓库。

## 结果

单位 MiB = 1024² 字节。

| 顺序与场景 | 私有工作集 MiB | 私有提交 MiB | GDI 均值 | USER 均值 |
| --- | ---: | ---: | ---: | ---: |
| 旧版默认六入口 | 19.62 | 29.67 | 25 | 25.38 |
| 新版默认六入口 | 19.06 | 26.72 | 25 | 25.63 |
| 添加两项，尚未启动应用/打开菜单 | 18.92 | 24.91 | 25 | 29.00 |
| 已实际启动、重命名、排序、移除 | 26.77 | 36.20 | 87 | 43.63 |
| 再导入 100 项并浏览各页，共 107 项 | 28.01 | 37.47 | 87 | 51.88 |
| 第一批 20 轮增删及主题切换 | 27.42 | 36.12 | 87 | 62.00 |
| 第二批 20 轮增删及主题切换 | 27.82 | 37.08 | 87 | 65.00 |
| 打开原生添加文件选择器 | 32.75 | 45.57 | 203.25 | 187.38 |
| 取消选择器后 | 32.07 | 44.46 | 109 | 86.00 |
| 隐藏卡片后 | 26.45 | 37.46 | 93 | 85.00 |

默认入口新旧差异在本次短时采样中为 −0.57 MiB 工作集、−2.95 MiB 提交，
只能说明没有观察到明显默认常驻增量，不能据此宣布优化节省了固定内存。
百项翻页阶段相对启动/菜单预热之后增加约 1.24 MiB 工作集、1.27 MiB 提交；
相对新版首次稳态则增加约 8.95 / 10.75 MiB，包含启动、菜单、COM 等开销。
不能把这两个比较口径混用，也不能把增长完全归因于图标像素。

两批编辑后第二批相对第一批增加约 0.40 MiB 工作集、0.96 MiB 提交；GDI 不变，
USER 从 62 到 65，handles 从 616 到 622。未观察到大幅线性上涨，
但短时样本及仍有变化的句柄不足以排除缓慢泄漏，需要后续长稳验证。
文件选择器关闭后没有立即回到打开前的进程计数，系统运行时保留部分资源；
不使用工作集清空或定时回收来掩盖它。低常驻内存与按需编辑峰值分别报告。

稳态平均 CPU 为 0–0.012%，选择器打开约 0.182%；这是短时均值，不是长期 p95 承诺。
GPU 进程显存计数返回 0，但采样器没有单独区分「没有匹配的 GPU 实例」与「真实零使用」，
因此本轮不据此声称零 GPU 成本。DWM 未定位到当前会话 PID，计数为 −1/不可用；
DWM 与系统提交增量未形成可用的受控比较，完整 GPU/DWM 成本仍待补测。

## 缓存与验收边界

应用的 CPU 图标 LRU 上限 3 MiB / 96 项，渲染位图上限六张，每张最多 128²×4 字节，
队列最多六项、单任务提取。独立测试实际填充到 3 MiB 并验证淘汰，暂停后缓存字节数为零。
本次 125% DPI 图标为 40×40 px，每张 6,400 字节；最后一轮编辑后五项缓存记录 32,000 字节。
8 MiB 仅为图标像素与临时缓冲的保守设计预算，不能限制 OS/Shell 分配或整个进程增长。
切换主题不复制四套图标；一页六项复用原窗口表面，不随入口总数创建更多窗口。

已通过添加导入、受控应用真实点击启动、中文重命名、跨页移动、移除保留源文件、
百项分页、40 轮增删/主题、文件选择器打开/取消与重启恢复。
缺测：真实 Explorer 拖放、商店应用特殊快捷方式、大量不同图标源、慢盘/断网链接、
多屏/高 DPI 完整矩阵、首次选择器瞬间峰值、三轮五分钟采样与 8 小时长稳。
合成链接使用系统 DLL 的 16 种图标，不能代表任意 100 个第三方应用的 Shell 开销。
