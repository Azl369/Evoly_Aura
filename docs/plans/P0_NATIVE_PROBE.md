## 要回答的问题

1. 原生空窗口到六个简单面板的基础内存增量是多少？
2. 缓存玻璃的稳态和解码峰值是否在预算内？
3. Acrylic 在具体窗口样式、桌面挂载与 HUD 下是否可靠？
4. 多窗口、DPI、多屏和 DWM 带来的成本如何增长？
5. 静态软件绘制与共享 GPU 设备各适合什么场景？

## 实验控制

仅改变一个变量，固定面板数量、尺寸、文本、壁纸和构建模式。
系统材质与缓存玻璃分别测，不只比较进程工作集。
桌面挂载与材质启用先分别成功，再验证组合；不能根据单项成功推断组合兼容。

分别记录：启动、60 秒预热、5 分钟稳定、拖动 / 缩放、隐藏与恢复。
遵循 [完整测量协议](../performance/PERFORMANCE_BUDGET.md)。

## 首轮交付

- 最小可运行程序和可复现构建命令。
- 基线报告：同机 3 次，附配置、提交 SHA、计数器口径。
- 窗口 / 材质组合兼容矩阵。
- 缓存、设备、句柄生命周期说明。
- 不满足预算时的成本分解、下一项实验和预算处理决策。

原型不包含完整文件管理、天气、云同步或插件商店。
