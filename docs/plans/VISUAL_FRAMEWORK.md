## 验收入口

双击根目录 Start-Aura.cmd 启动桌面卡片。
默认启动已于 2026-11-20 调整为桌面驻留，避免遮挡应用；显式 -Preview 才进入普通悬浮。
托盘或 Ctrl+Alt+F10 可唤起，右键隐藏或 Esc 收起；切换应用只改变普通窗口遮挡，不再自动回挂桌面。
2026-11-22：按用户要求，普通界面只保留唤起、隐藏两个显示动作；移除手动回桌面及持久模式切换入口。
结束编辑只保存和锁定布局、取消临时置顶，保持卡片可见；不再自动返回壁纸桌面层。
快捷键：Ctrl+Alt+F9 编辑；F10 显示/隐藏；F12 退出。
