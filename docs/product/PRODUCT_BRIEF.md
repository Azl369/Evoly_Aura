# 产品范围

创建日期：2026-11-19
状态：初始规划

## 产品目标

让用户把 Windows 桌面编排成安静、清晰的玻璃空间，并能把当前需要的信息提为悬浮 HUD。
低内存是架构约束，与视觉和交互一起设计。

核心用户：希望桌面整洁、美观，长期运行且不愿为装饰承受明显资源开销的 Windows 用户。

## 核心体验

| 状态 | 用途 | 基本操作 |
| --- | --- | --- |
| 桌面态 | 陈列快捷方式、文件夹和基础组件 | 打开项目、查看信息 |
| 悬浮态 | 按需唤起查看信息 | 普通层级、明确单卡置顶、拖动、吸附、临时隐藏 |
| 编辑态 | 编排桌面 | 移动、缩放、设置主题、保存布局 |

模式切换尽量复用面板状态与资源。闲置淡化和短动画受性能策略约束。
鼠标穿透必须保留明确的快捷键或托盘恢复入口。

## 第一版候选范围

- 面板创建、拖动、缩放、锁定、贴边及相互吸附。
- 快捷方式与只读文件夹视图。
- 时钟、便签、专注计时、系统状态组件。
- 桌面 / HUD 切换；主题、色调、圆角、玻璃强度设置。
- 托盘、可选开机启动、布局备份与恢复。
- 多屏布局与 DPI 变化后的安全位置恢复。

P0 / P1 先做时钟、文字、图标等最小面板；其余按里程碑逐步加入。
系统状态组件必须能关闭；秒级刷新不是所有组件的默认行为。

## 文件与隐私语义

第一版文件夹面板展示原位置内容，快捷方式保存引用。
不会因“整理桌面”默认移动、删除真实文件或隐藏系统桌面图标。
如果以后增加此类能力，必须提供预览、明确动作和可恢复策略。
便签与布局本地保存；无账号要求。天气等网络能力后置。

## 后续候选

天气、媒体控制、照片组件、壁纸取色、场景切换、Evoly 数据对接。
剪贴板涉及敏感内容和长期缓存，单独设计后再评估。

首版不包含：网页插件商店、任意脚本运行环境、动态壁纸引擎、云同步、Explorer 注入 DLL。

## 成功条件

- 核心面板可长期稳定常驻，无持续内存增长。
- 字体、玻璃和 hover 效果在深浅壁纸下清晰。
- 显示器断开、缩放变化和 Explorer 重启后能恢复。
- 性能目标按固定测量协议验证，未达标时先定位成本再增加功能。
