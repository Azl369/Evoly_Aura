# 测试与验收

## 当前阶段

当前优先桌面效果和功能验证，完整性能验收按用户要求后置。
Test-Workspace.ps1 检查七窗口、真实拖动/缩放、主题、专注、中文便签、桌面/HUD、
隐藏/恢复、重复启动及重启持久化。Capture-Workspace.ps1 检查实际原生界面截图。

执行 tools/scripts/Validate-Workspace.ps1，检查必需文件、预留目录、文档相对链接和 JSON。
GitHub Actions 使用同一入口。
原生代码通过 Build-Native.ps1 构建 Release 与 CTest；Test-Probe.ps1 检查六组窗口/材质正常绘制并退出。
原生 CI 只构建与运行 core 测试，不在托管 runner 宣称桌面视觉或精确性能通过。
Test-Lifecycle.ps1 将实际重绘与两批切换后的资源检查结合；Test-Visual.ps1 用自建网格检查模糊。
以上脚本的存在不代表每项已验收，执行结果与缺测项记录在阶段性能报告中。

## 原型与后续自动化

- 纯布局、吸附边界、DPI 坐标转换：使用小型确定性单元测试。
- 调度器：验证分钟边界、隐藏时停采样、任务取消与过期结果丢弃。
- 配置：验证格式迁移、无效类型、损坏文件、原子替换和备份恢复。
- 窗口：集成测试检查模式切换、托盘恢复、退出和句柄释放。
- 性能：普通 CI 只做功能与资源泄漏冒烟，精确预算在固定机器测量。
- 渲染：真实 Windows 截图与人工检查；不以脆弱逐像素断言替代材质验证。

根据代码风险添加有价值的测试，不为目录占位或纯文档堆砌测试。

## 人工验收矩阵

| 场景 | 通过条件 |
| --- | --- |
| 桌面 / HUD 来回切换 100 次 | 内容与位置保留，没有失联透明窗口 |
| 拖动、缩放与吸附 | 不跳屏，文字清晰，缓存不会无界增长 |
| 多屏断开与重接 | 面板可见且能恢复合理位置 |
| 100% / 150% / 200% DPI | 位置、命中区域和文字尺寸一致 |
| Explorer 重启 | 能重挂载或回退并保留托盘 / 恢复入口 |
| 锁屏、睡眠与设备丢失 | 无崩溃，资源可重建 |
| 禁用系统透明、高对比 | 可读、可操作 |
| 输入与键盘 | 便签支持中文输入法，焦点和快捷键不互相吞掉 |
| 配置损坏 | 自动回退，用户内容不被覆盖丢失 |
| 大目录 | 列表虚拟化，图标按需加载，无阻塞 UI |
| 隐藏与设置关闭 | 无无用刷新；可释放的资源按策略回收 |
| 长稳 | 遵循性能协议，区分预热与泄漏 |

测试报告同时记录未测平台；不得把单台 Windows 11 结果扩写为所有 Windows 版本兼容。
